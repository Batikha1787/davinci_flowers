# DaVinci Flowers — Интернет-магазин цветов с лёгкой RAG-системой и админ-панелью

Проект онлайн-магазина цветов **DaVinci Flowers** (г. Астана), дополненный интеллектуальным ассистентом на базе лёгкой **RAG-системы** (Retrieval-Augmented Generation) и удобной панелью администратора для управления базой знаний.

---

## 🌸 Возможности

1. **Лёгкая и быстрая RAG-система**:
   - Локальная база данных **SQLite** (`davinci.db`) со встроенным каскадным удалением фрагментов вместе с документами (`ON DELETE CASCADE`).
   - Нарезка текста на фрагменты по 500–800 символов с перекрытием ~100 символов без разрыва предложений и абзацев.
   - Эмбеддинги через модель OpenAI `text-embedding-3-small` (пакетная обработка).
   - Расчёт косинусного сходства на встроенных структурах Python без тяжёлых внешних зависимостей.
   - Калиброванный порог сходства (`0.3`): если релевантных данных нет, генеративная модель **не вызывается**, а посетитель получает вежливый ответ флориста без технических терминов.
   - Строгая системная инструкция: ответы формируются строго по фрагментам, текст данных изолирован от команд, в конце ответа указываются источники (`📌 Источник: ...`).

2. **Панель администратора (`/admin`)**:
   - Защита входа по паролю из переменной окружения `ADMIN_PASSWORD` (по умолчанию `davinci2026`).
   - Загрузка документов `.txt` и `.md` (лимит до 1 МБ, поддержка больших текстов в сотни строк).
   - Корректная обработка имён файлов с сохранением кириллицы и буквы «ё».
   - Просмотр списка документов с количеством фрагментов, удаление и кнопка полной переиндексации.
   - Прямая ссылка на админку из меню и подвала сайта.

3. **Виджет чат-бота на главной странице**:
   - Красивая всплывающая кнопка в правом нижнем углу в фирменных оттенках DaVinci Flowers.
   - Быстрые подсказки-чипы («Пионы: уход», «Популярные букеты», «Доставка»).
   - Адаптивный интерфейс для мобильных телефонов и компьютеров.
   - Встроенный Rate Limiter (ограничение частоты запросов с одного IP).

## 🚀 Требования и запуск

### Системные требования
* **Python**: версия **3.9** или выше (уже предустановлен в macOS).
* Сторонние библиотеки не требуются (используются стандартные модули `sqlite3`, `http.server`, `urllib`, `json`).

### 1. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```

Откройте файл `.env` и при необходимости укажите ваш ключ OpenAI API:
```ini
# Ключ OpenAI API (платформа platform.openai.com)
OPENAI_API_KEY=sk-...

# Пароль для входа в панель администратора (/admin)
ADMIN_PASSWORD=davinci2026

# Порт сервера
PORT=8000

# Порог косинусного сходства для ответа RAG
RAG_SIMILARITY_THRESHOLD=0.3
```

> **Примечание**: При отсутствии ключа OpenAI система автоматически работает в локальном демонстрационном режиме, позволяя полноценно тестировать косинусное сходство, калибровку ловушек и веб-интерфейс.

### 2. Запуск сервера
Запустите сервер из корневой папки проекта:
```bash
python3 server.py
```
После запуска сайт доступен по адресу:
* Главная страница магазина и чат: **http://localhost:8000/**
* Панель администратора базы знаний: **http://localhost:8000/admin**

## 🧪 Проверка качества и скрипт тестирования (eval/)

В проекте настроен автоматический набор тестов для проверки качества поиска и отсечения ловушек:
* `sample_docs/` — примеры справочников магазина (уход за пионами, правила доставки).
* `eval/questions.json` — 3 целевых вопроса и 1 контрольная ловушка вне темы.
* `eval/test_rag.py` — скрипт проверки, отображающий реальные коэффициенты сходства.

Запуск проверки:
```bash
python3 eval/test_rag.py
```

## 🔒 Безопасность

* Секретный ключ `OPENAI_API_KEY` и пароль `ADMIN_PASSWORD` хранятся исключительно на сервере и никогда не передаются в браузер или логи.
* Файлы `.env` и локальная база данных `*.db` добавлены в `.gitignore`.
* Встроен In-Memory Rate Limiter, защищающий эндпоинт чата от перегрузки (до 30 запросов в минуту с одного IP).
